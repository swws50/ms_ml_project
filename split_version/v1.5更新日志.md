# 🔬 智能峰发现功能更新日志

## 版本信息

- **更新版本**: v1.5.0 - 智能峰发现版
- **更新日期**: 2025年7月18日
- **兼容性**: 完全向后兼容传统方法

---

### ✨ 新增功能

#### 1. **智能峰发现模式**

- **核心技术**: 集成 pyOpenMS 专业质谱分析库
- **自动化程度**: 无需人工预设 m/z 值，智能发现最优特征峰
- **处理能力**: 每个文件可发现数百个峰候选，最终选择最佳特征

#### 2. **ML导向的共识峰算法**

- **双类别要求**: 确保特征在 HC 和 LC 两类中都存在（共同特征）
- **区分性评估**: 自动计算倍数变化，筛选有区分力的峰
- **覆盖率控制**: 要求特征在足够比例的文件中出现
- **智能排序**: 基于 ML 友好性评分自动排序选择最佳特征

#### 3. **动态归一化系统**

- **全局扫描**: 两轮处理，先扫描全局最大强度值
- **科学归一化**: 使用实际数据最大值作为归一化因子
- **因子保存**: 自动保存归一化信息，确保预测一致性

#### 4. **智能预测适配**

- **自动检测**: 预测时自动识别训练方法和特征
- **特征匹配**: 从训练数据 CSV 自动提取特征 m/z 值
- **归一化同步**: 使用训练时相同的归一化因子处理预测样本

## 🔧 技术改进

### 🎯 **算法优化**

#### **峰发现算法**

```
传统方法: 48个固定m/z → 智能方法: 动态发现+筛选50个最佳特征
```

#### **特征选择策略**

- **覆盖率要求**: 至少在20%的文件中出现
- **区分性要求**: HC/LC间至少30%强度差异  
- **稳定性评估**: 基于变异系数的峰稳定性分析

#### **归一化改进**

```
传统方法: 固定因子(871.77) → 智能方法: 动态全局最大值
```

### 📁 **配置系统**

#### **新增配置参数** (`config.py`)

```python
# 智能峰发现参数
MAX_FEATURES = 50                # 最大特征数量
MIN_OCCURRENCE_RATE = 0.2        # 最小出现频率
MIN_FOLD_CHANGE = 1.3            # 最小倍数变化
SIGNAL_TO_NOISE = 1.0            # 信噪比阈值
ENABLE_FALLBACK = True           # 启用备用策略
```

- 所有参数可在 `config.py` 中简单调整
- 无需理解技术细节，直接修改数值即可
- 内置合理默认值，开箱即用
