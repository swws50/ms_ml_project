## 概述

本版本新增 **Max归一化方法**（除以样本内最大峰强度），解决了TIC归一化导致共识特征峰数量不足的问题。

---

## 问题背景

### 现象描述

使用原始数据（raw data）进行共识峰识别时，能够发现足够数量的特征峰用于分类模型训练。但启用TIC归一化（sum方法）后，共识峰数量大幅减少，导致后续机器学习模型缺乏足够的特征输入。

### 根本原因分析

TIC归一化的设计目的是消除样本间的技术变异（如进样量差异、仪器响应波动）。当归一化正确执行时，**样本间的强度差异被压缩**，这意味着：

1. 原本由技术变异造成的"伪差异"被消除（预期行为）
2. 但同时，部分真实的生物学差异也可能被过度压缩
3. 共识峰筛选依赖 `fold_change` 指标，归一化后各类别间的fold change下降，导致更多峰被过滤

### 数据对比

| 归一化方法        | 模型性能表现                                                 |
| ------------ | ------------------------------------------------------ |
| **Max归一化**   | Sensitivity: 0.838, Specificity: 0.848, AUC-ROC: 0.843 |
| **Raw Data** | Sensitivity: 0.796, Specificity: 0.867, AUC-ROC: 0.831 |

Max归一化在保持敏感度的同时，整体性能优于原始数据。

---

## 解决方案

### 新增归一化方法

在 `NormalizationManager` 中新增 `max` 方法，将每个样本的所有峰强度除以该样本的最大峰强度：

```python
# 归一化因子计算（_discover_peaks_from_file方法）
self.normalization_stats[file_id] = {
    'sum': results['intensity'].sum(),      # TIC
    'median': results['intensity'].median(), # 中位数
    'max': results['intensity'].max(),       # 最大峰 ← 新增
}
```

### 归一化公式

$$I_{normalized} = \frac{I_{raw}}{I_{max}}$$

其中：

- $I_{raw}$：原始峰强度
- $I_{max}$：该样本内的最大峰强度
- $I_{normalized}$：归一化后强度，范围 [0, 1]

### UI更新

分类对话框的归一化选项已更新：

```python
values=["不归一化", "sum (总和)", "median (中位数)", "max (最大峰)"]
```

默认值从 `sum` 改为 `max`。

## 技术细节

### 为什么Max归一化效果更好？

| 特性      | TIC (sum) | Max     |
| ------- | --------- | ------- |
| 归一化因子   | 所有峰强度总和   | 单个最大峰强度 |
| 受低丰度峰影响 | 高（累加效应）   | 无       |
| 相对强度保持  | 可能被压缩     | 较好保持    |
| 对离群峰敏感  | 低         | 高       |

Max归一化保留了峰之间的相对强度关系，同时将所有样本的强度范围统一到 [0, 1]，这对于后续的fold change计算和特征选择更为有利。

### 关于数据泄露的说明

本归一化属于**样本内操作**（within-sample normalization），每个样本独立计算归一化因子，不涉及跨样本信息。因此：

- ✅ 可以在数据划分前执行
- ✅ 不存在数据泄露问题
- ✅ 与后续CV框架兼容

这与机器学习中的特征缩放（如StandardScaler）性质不同，后者是跨样本操作，需要在CV循环内执行。

## 验证建议

1. **回归测试**：使用相同数据集，对比sum、median、max三种方法的共识峰数量和模型性能
2. **边界情况**：测试样本中存在极端离群峰的情况
3. **批次一致性**：验证不同批次数据使用max归一化后的性能稳定性
