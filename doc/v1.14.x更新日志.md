## v1.14.1（2026-04-11）

### 新增：向导中英文切换（`help_system.py` / `main.py`）

#### 背景

软件面向国际化使用场景，需要支持中英文界面切换。考虑到帮助向导内容固定、适合静态双语实现，作为首个语言切换功能落地；其余动态界面的翻译留待后续版本逐步推进。

#### 实现

**`help_system.py`**

- `__init__` 新增 `self.lang = "zh"` 语言状态字段
- 新增 `toggle_lang()` 方法：在 `"zh"` / `"en"` 间切换，返回新语言值
- 原 `show_wizard()` 改为分发器，根据 `self.lang` 调用对应语言版本：
  - `_show_wizard_zh()`：原中文向导（内容和结构不变，仅改名）
  - `_show_wizard_en()`：新增英文向导，结构与中文版完全一致

英文向导各 tab 对照：

| 中文 tab | 英文 tab |
|---|---|
| 0. 须知 | 0. Disclaimer |
| 1. 介绍 | 1. Overview |
| 2. 数据预处理 | 2. Preprocessing |
| 3. 模型训练 | 3. Training |
| 4. 样本预测 | 4. Prediction |

底部复选框和确认按钮也对应翻译：
- "启动时显示此向导" → "Show this guide on startup"
- "我已知晓免责声明，开始使用" → "I have read the disclaimer — let's start"

**`main.py`**

- 菜单栏末尾新增 `🌐中/EN` 语言切换按钮
- 新增 `_toggle_language()` 方法：
  - 调用 `help_system.toggle_lang()` 切换语言状态
  - 用 `menubar.entryconfigure(last_idx, label=...)` 同步更新按钮标签（`🌐中/EN` ↔ `🌐EN/中`）

切换后再点"打开使用向导"即显示对应语言版本；其他界面文字不受影响。

## 后续设想：动态界面国际化（未实现）

### 方案

采用集中式字典翻译，不引入 `gettext` 等外部工具链，保持轻量。

**新增 `i18n.py`**

```python
_lang = "zh"          # 与 HelpSystem.lang 同步

_texts = {            # key = 中文原文，value = 英文译文
    "保存": "Save",
    "取消": "Cancel",
    ...
}

def t(key: str) -> str:
    if _lang == "zh":
        return key
    return _texts.get(key, key)

def set_lang(lang: str): ...
def get_lang() -> str: ...
```

- 中文为 key（`t("保存")` 在中文模式直接返回 key，零额外开销）
- 英文模式查字典，缺失 key 返回原文，不会崩溃

**组件刷新**

静态控件（创建时确定文字）：创建时 `text=t("保存")`；切换语言需重建或维护引用列表。

动态控件（运行时 `.configure(text=...)`）：已有引用，直接在语言切换回调中遍历更新。

### 工作量预估

经统计，当前全部 `.py` 文件中共约 **110 条**唯一中文 GUI 字符串。其中：

- 帮助向导和 About 页：已通过静态双语函数处理，**不需要** `i18n.py` 接入
- 剩余需动态切换的按钮、标签、状态文字：约 **40–50 条**

分文件工作量：

| 文件 | 主要涉及内容 |
|---|---|
| `ui_components.py` | 面板标题、按钮、状态标签、chip 文字 |
| `main.py` | 菜单标签、对话框标题、messagebox 文字 |
| `project_manager.py` | 项目管理对话框的标签、按钮、提示文字 |
| `parameter_tuning_window.py` | 参数调优窗口按钮和状态标签 |

### 注意事项

- **chip 状态文字**（如 `"○ 预处理: 等待开始"`）由程序逻辑动态写入，需单独处理格式化字符串，不能直接用 `t(key)` 
- **带变量的拼接文字**（如 `f"已选择: {filename}"`）需拆分为模板 key + 变量，或保持英文拼接
- 语言切换时若对话框已打开，需关闭后重开才能刷新（可接受）
- `messagebox` 标题和内容也需替换，但优先级低于主界面控件
