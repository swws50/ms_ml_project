# 参数调优窗口 - 使用说明

## 功能简介
简洁的参数调优窗口，用于在线查看和修改机器学习模型的参数配置。

## 文件说明

### 1. parameter_tuning_window.py
核心窗口模块，提供参数显示和编辑功能。

**主要特性：**
- ✅ 读取选定模型的默认参数
- ✅ 以表单形式显示所有参数
- ✅ 支持在线修改参数值
- ✅ 自动类型转换（int, float, bool, tuple等）
- ✅ 重置为默认值功能
- ✅ 保存修改到全局配置

### 2. integration_example.py
集成示例代码，展示如何在主界面中添加参数调优功能。

### 3. demo_parameter_tuning.py
独立演示程序，可直接运行测试参数调优窗口。

## 快速开始

### 方法1：在现有项目中集成

在你的 `ui_components.py` 的 `ControlPanel` 类中添加：

```python
# 在 _create_model_controls 方法中添加按钮
def _create_model_controls(self):
    # ... 现有代码 ...
    
    # 添加参数调优按钮
    self.components['tune_button'] = ctk.CTkButton(
        self.frame, 
        text="⚙️ 参数调优", 
        width=120, 
        command=self._on_tune_parameters
    )
    self.components['tune_button'].grid(row=2, column=3, padx=5, pady=5)

# 添加回调方法
def _on_tune_parameters(self):
    from parameter_tuning_window import ParameterTuningWindow
    
    current_model = self.components['model_selector'].get()
    tuning_window = ParameterTuningWindow(self.parent, current_model)
    self.parent.wait_window(tuning_window)
```

### 方法2：运行演示程序

```bash
python demo_parameter_tuning.py
```

## 使用流程

1. **选择模型**
   - 在主界面或演示程序中选择要调优的模型

2. **打开调优窗口**
   - 点击"参数调优"按钮或相应菜单项

3. **查看参数**
   - 窗口会显示当前模型的所有默认参数
   - 每个参数都有对应的输入框

4. **修改参数**
   - 直接在输入框中修改参数值
   - 支持的类型：整数、浮点数、布尔值、元组、列表等

5. **保存或重置**
   - **保存**：应用修改，更新到 MODEL_CONFIGS
   - **重置**：恢复所有参数为默认值
   - **取消**：关闭窗口，不保存修改

## 支持的模型

所有在 `config.py` 的 `MODEL_CONFIGS` 中定义的模型：

- RandomForestClassifier
- LinearSVC
- LinearDiscriminantAnalysis
- LogisticRegressionCV
- MLPClassifier
- PLSRegression

## 参数示例

### PLSRegression
```python
{
    "n_components": 4,          # 主成分数量
    "scale": False,             # 是否标准化
    "max_iter": 300,            # 最大迭代次数
    "tol": 1e-06               # 收敛容差
}
```

### RandomForestClassifier
```python
{
    "n_estimators": 500         # 决策树数量
}
```

### MLPClassifier
```python
{
    "hidden_layer_sizes": (100, 200, 100),  # 隐藏层结构
    "activation": 'logistic',                # 激活函数
    "max_iter": 2000                        # 最大迭代次数
}
```

## 注意事项

1. **参数格式**
   - 整数：直接输入数字，如 `500`
   - 浮点数：包含小数点，如 `1e-06` 或 `0.000001`
   - 布尔值：输入 `True` 或 `False`
   - 元组：使用括号，如 `(100, 200, 100)`
   - 字符串：直接输入文本，如 `logistic`

2. **实时生效**
   - 保存后的参数会立即更新到 `MODEL_CONFIGS`
   - 下次训练模型时将使用新参数

3. **参数验证**
   - 输入错误格式会提示错误信息
   - 建议先测试小范围参数调整

## 常见问题

**Q: 修改参数后需要重启程序吗？**
A: 不需要，参数会立即更新到全局配置。

**Q: 如何恢复默认参数？**
A: 点击"重置"按钮即可恢复。

**Q: 参数修改会保存到文件吗？**
A: 默认只在内存中修改。如需持久化，可添加配置文件保存功能。

**Q: 可以为不同数据集使用不同参数吗？**
A: 可以，建议在训练前打开调优窗口设置参数。
