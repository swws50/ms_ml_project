## 问题描述

`model_training.py` 中计算ROC曲线时，错误地使用了**硬标签**（0/1二值）而非**连续分数**。

**错误代码位置**：

- `train_single_iteration()` 方法，第95行
- `train_model()` 方法，第207行

**错误代码**：

```python
fpr, tpr, thresholds = roc_curve(test_y, test_y_pred)  # test_y_pred是0/1硬标签
```

### 原理分析

ROC曲线的绘制需要遍历不同阈值，计算每个阈值下的TPR和FPR：

| 输入类型      | 阈值数量  | ROC点数 | 曲线形态 |
| --------- | ----- | ----- | ---- |
| 硬标签 (0/1) | 2-3个  | 2-3个  | 阶梯状  |
| 连续分数      | 等于样本数 | 平滑    | 曲线   |

`sklearn.roc_curve()` 会将输入的所有唯一值作为候选阈值。当输入只有0和1两个值时，只能产生极少的阈值点。

| 模型                         | 方法                       | 输出含义      |
| -------------------------- | ------------------------ | --------- |
| PLSRegression              | `.predict()`             | 回归预测值     |
| RandomForestClassifier     | `.predict_proba()[:, 1]` | 类别1的概率    |

## 相关知识点

### ROC曲线计算流程

1. 获取模型的连续输出分数
2. 将所有唯一分数值作为候选阈值
3. 对每个阈值：
   - 分数 ≥ 阈值 → 预测为阳性
   - 计算 TPR = TP / (TP + FN)
   - 计算 FPR = FP / (FP + TN)
4. 以 FPR 为横轴、TPR 为纵轴绘制曲线

### 为什么硬标签会导致问题

```python
test_y_pred = [0, 1, 1, 0, 1, 0]  # 硬标签，只有0和1

# roc_curve会用这些唯一值作为阈值：
# 阈值 > 1: 全部预测为0 → (FPR=0, TPR=0)
# 阈值 > 0: 部分预测为1 → (FPR=x, TPR=y)  
# 阈值 ≤ 0: 全部预测为1 → (FPR=1, TPR=1)

# 结果只有3个点！
```
