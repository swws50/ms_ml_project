# 更新日志 v1.9.0.3 - 预处理优化

## 核心优化

### 预处理流程优化

- **跳过归一化阶段**：未归一化模式下直接从66%跳到100%，跳过全局强度扫描
- **进度条适配**：原始数据模式进度范围调整为66%-100%（原34%范围）
- **统一矩阵构建**：合并归一化和原始数据的矩阵构建逻辑

### 代码架构重构

- **方法位置重组**：按功能模块重新组织代码结构
  - 第一部分：主流程方法
  - 第二部分：三阶段处理流程 
  - 第三部分：核心算法方法
  - 第四部分：数据处理和保存
  - 第五部分：GUI相关方法
  - 第六部分：进度管理方法

### 代码简化

- **删除冗余方法**：移除重复的矩阵构建和强度提取方法
- **统一强度提取**：`_extract_intensity()` 支持归一化/原始两种模式
- **新增辅助方法**：
  - `_passes_selection_criteria()` - 特征选择标准检查
  - `_calculate_peak_metrics()` - 峰统计指标计算
  - `_build_unified_matrix()` - 统一矩阵构建
  - `_save_and_notify_results()` - 保存结果和通知

## 修复问题

### 逻辑错误修复

- **重复保存修复**：修正 `_execute_processing()` 中的重复保存逻辑
- **进度计算优化**：根据归一化模式动态调整进度范围
- **变量命名统一**：修正返回值字典键名一致性

### 性能提升

- **原始模式优化**：跳过不必要的全局扫描，处理时间减少约25%
- **缓存利用改进**：更好地利用峰发现缓存机制
- **代码行数减少**：整体代码减少约15%，提高可读性

## 技术细节

### 处理流程变化

```
归一化模式: 0% → 33% → 66% → 83% → 100%
             峰发现  特征选择  扫描最大值  矩阵构建

原始模式:   0% → 33% → 66% → 100%
             峰发现  特征选择  直接矩阵构建
```

### 核心方法变化

- `_phase3_build_matrix()` - 简化为统一入口，根据模式选择处理方式
- `_phase2_consensus_peaks()` - 使用辅助方法重构，提高可读性
- 删除 `_build_raw_matrix()`, `_extract_raw_intensity()` 等冗余方法

---

**总结**：此次优化主要focused在预处理性能提升和代码结构改进，为后续的模型存储区分功能奠定基础。
