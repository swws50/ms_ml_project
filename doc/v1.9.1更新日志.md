# 更新日志 v1.9.1

## 预测面板重构

### UI改进
- **三栏布局**：模型设置 → 操作按钮 → 结果显示
- **模型选择优化**：下拉框改为文件选择按钮
- **状态显示调整**：兼容性和归一化状态右对齐显示
- **结果复制功能**：可选择和一键复制预测结果

### 模型管理升级
- **智能文件选择**：默认定位到模型目录，预选best_model.joblib
- **带时间戳保存**：训练完成自动生成详细文件名
- **命名规范**：`{模型类型}_{归一化状态}_{时间戳}.joblib`
- **移除冗余**：不再保留默认best_model.joblib文件

### 交互优化
- **按钮布局**：预测和模型信息按钮左右并排
- **状态标签**：实时显示选择状态和数据模式
- **文件显示**：选择后按钮显示已选择文件名

## 技术改进

### 代码清理
- **重复方法移除**：删除main.py中的重复handle_predict_file
- **组件统一**：result_label改为result_textbox统一接口
- **错误修复**：解决组件引用不匹配问题

### 文件命名示例
```
PLSRegression_normalized_20241202_143021.joblib
RandomForestClassifier_raw_20241202_144512.joblib
```

---

**总结**：此版本重点优化预测工作流，提供更直观的模型选择和管理体验，支持详细的训练记录追踪。
