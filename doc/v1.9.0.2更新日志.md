# 更新日志 v1.9.0.2

## 核心功能更新

### 归一化系统重构
- **移除预设归一化因子**：删除config.py中的硬编码NORMALIZATION_FACTOR
- **统一数据管理**：归一化因子完全通过data_store管理，预处理时生成，预测时引用
- **动态模式切换**：添加菜单栏归一化开关，支持实时切换归一化/原始数据模式
- **智能文件命名**：根据归一化状态自动生成文件名（normalized_ms_data.csv / raw_ms_data.csv）

### UI改进
- **状态显示同步**：控制面板和预测面板增加归一化状态实时显示
- **预测面板布局优化**：归一化状态标签移至面板标题右侧，改用grid布局
- **进度系统集成**：预处理进度与全局进度条完全同步

### 代码架构优化
- **依赖关系简化**：移除config.py中的归一化文件读写逻辑
- **数值溢出修复**：PLS预测中添加数值范围限制，避免exp溢出警告
- **错误处理改进**：归一化模式下强制要求归一化因子，非归一化模式直接使用原始值

## 技术细节

### 修改文件
- `data_store.py`：新增归一化设置管理
- `config.py`：移除硬编码因子，简化函数逻辑  
- `data_preprocessor.py`：集成归一化开关，动态路径生成
- `feature_detector.py`：模式感知的强度提取
- `model_predictor.py`：修复数值溢出，状态显示集成
- `main.py`：菜单栏开关，状态同步机制
- `ui_components.py`：预测面板grid布局，状态标签重定位

### 数据流程
```
预处理 → 生成归一化因子 → 存储到data_store → 预测时引用
开关切换 → 实时更新UI状态 → 影响数据处理方式
```
