## 一、图表归档系统重构

### 1.1 新增 latest + archive 模式

**问题背景**: 原有每次训练都生成带时间戳的图表文件，导致 `/charts` 目录文件堆积混乱。

**解决方案**: 

- `/charts/` 目录直接存放最新图表（固定文件名）
- `/charts/archive/YYYYMMDD_HHMMSS/` 存放历史归档

**目录结构**:

```
/charts/
├── ClassPerformance.png      ← 最新图表
├── BalanceMetrics.png
├── ConfusionMatrix.png
├── ROC_Curve.png
├── MetricsTable.csv
├── PLS_Thresholds.png
└── archive/
    ├── 20250127_143025/      ← 按训练时间归档
    │   ├── ClassPerformance.png
    │   ├── MetricsTable.csv
    │   └── ...
    └── 20250127_102010/
        └── ...
```

### 1.2 output_manager.py 新增方法

| 方法                                   | 说明                  |
| ------------------------------------ | ------------------- |
| `start_training_session()`           | 开始训练会话，生成时间戳        |
| `end_training_session()`             | 结束训练会话              |
| `archive_current_charts()`           | 归档当前图表到 archive 子目录 |
| `get_archive_sessions(limit=10)`     | 获取归档会话列表            |
| `cleanup_old_archives(keep_count=N)` | 手动清理旧归档（未自动调用）      |

### 1.3 归档支持的文件类型

```python
['.png', '.jpg', '.jpeg', '.svg', '.pdf', '.csv']
```

## 二、MetricsTable 输出格式变更

### 2.1 PNG → CSV

**变更原因**: PNG 图片无法复制数据，不便于后续使用。

**文件变更**:

- 输出文件: `MetricsTable.png` → `MetricsTable.csv`
- 编码格式: `utf-8-sig`（带 BOM，Excel 可正确识别中文）

**CSV 结构**:

```csv
Metric,Value,±CI,95% CI Range
Sensitivity (TPR),0.838,±0.025,[0.813, 0.863]
Specificity (TNR),0.848,±0.022,[0.826, 0.870]
...
```

### 2.2 GUI 表格显示

使用 `tkinter.ttk.Treeview` 在 GUI 中渲染 CSV 数据：

- 交替行颜色（白色/#f0f4f8）
- 字体: Arial 12
- 行高: 45px
- 右键菜单支持"复制全部"

**相关函数**:

- `_create_table_view(parent, csv_path, root)` - 创建表格视图
- `_create_image_view(parent, image_path, notebook, tab_name)` - 创建图片视图

## 三、代码变更清单

### visualization.py

1. **generate_performance_charts()**
   
   - 移除时间戳文件名，改用固定文件名
   - 调用 `archive_current_charts()` 归档旧图表
   - MetricsTable 输出改为 CSV 格式

2. **generate_class_performance_chart()** / **generate_balance_metrics_chart()** / **generate_confusion_matrix_with_stability()**
   
   - 移除 `timestamp` 参数
   - 使用 `OUTPUT_FILES` 中的固定路径

3. **create_visualization_tabs()**
   
   - 重构为分发逻辑，根据文件类型调用不同视图
   - CSV → `_create_table_view()`
   - 图片 → `_create_image_view()`

4. **新增函数**
   
   - `_create_table_view()` - Treeview 表格渲染
   - `_create_image_view()` - 图片渲染（从原函数提取）

### output_manager.py

1. **新增属性**
   
   - `_current_session_timestamp` - 当前训练会话时间戳

2. **新增方法**
   
   - `start_training_session()`
   - `end_training_session()`
   - `get_session_timestamp()`
   - `archive_current_charts()`
   - `get_archive_sessions()`
   - `cleanup_old_archives()`

3. **修改方法**
   
   - `_create_project_directories()` - 自动创建 archive 子目录
   - `get_results_summary()` - 增加归档信息统计

## 五、注意事项

1. **归档不自动清理**: `cleanup_old_archives()` 需手动调用
2. **CSV 编码**: 使用 `utf-8-sig` 确保 Excel 兼容
3. **向后兼容**: 原有函数签名保持不变，可直接替换文件
