# v1.15.x 更新日志

## 背景与动机

通过与业界标准代谢组学 SOP 的系统对比，发现 v1.14.x 的预处理流程存在两类问题：

**问题一：特征选取缺乏学术规范**
阶段2通过自制的 `ml_score = fold_change × coverage` 排序并硬性截取前50个特征。该做法缺乏统计检验支撑，且两个问题不独立——若批次效应与类别标签共线，fold change 筛出的"特征"实为批次标记物，而非生物学差异。

**问题二：批次间差异导致混合批次后预测性能大幅下降**
当前归一化仅做样本内强度缩放（max/median/sum），对样本间系统性偏移无效。混合批次后性能下降，根本原因是模型学到了批次差异而非生物学差异。

**更深层的根因：缺失了业界默认的数据处理步骤**
从"峰拾取结果"到"可用于建模的特征矩阵"，整个中间过程缺失了质量过滤层、log 变换、Pareto 缩放、正确的缺失值填补等业界默认步骤，导致后续所有统计分析均建立在错误假设上。

v1.15.x 目标：系统性补齐与业界 SOP 的差距，使预处理流程达到可在论文中完整描述的学术规范。

## 完整的标准预处理流程（目标架构）

```
峰拾取（pyOpenMS PeakPickerHiRes）
  ↓
跨样本峰对齐
  ↓
质量过滤层 ──────────────────────────────────────────────
  ├─ 空白峰过滤     → 样本/空白强度比 < 5:1 的峰剔除
  ├─ 缺失值过滤     → 在 > 50% 样本中缺失的峰剔除
  └─ QC样本CV过滤  → QC样本中 CV > 20~30% 的峰剔除（分析重现性差）
  ↓
缺失值填补（half-minimum，对过滤后剩余峰）
  ↓
样本内归一化（TIC / median）
  ↓
批次校正（ComBat / QC比例校正）
  ↓
log₂(x+1) 变换
  ↓
Pareto scaling
  ↓ ─── 以上步骤产出"特征备选池" ───
统计检验（Wilcoxon + BH-FDR）+ Fold Change 过滤
  ↓
最终特征矩阵（用于建模）
```

## 关于变异系数（CV）的两种用法

CV 在流程中出现两次，**含义和操作方向相反**，需严格区分：

| 位置          | 计算对象               | CV 含义   | 操作                            |
| ----------- | ------------------ | ------- | ----------------------------- |
| 质量过滤层（QC样本） | 同一峰在多个 QC 重复样本间的波动 | 分析仪器重现性 | CV **高** → **剔除**（这个峰测不准，是噪声） |
| 特征选择层（生物样本） | 同一峰在所有生物样本间的波动     | 生物学变异程度 | CV **高** → 可能有区分度，但仍需统计检验确认   |

**注意**：生物样本中 CV 高不等于特征有效——高 CV 可能是真实生物学差异，也可能是样本质量不均或批次噪声。因此生物样本的 CV 只能辅助参考，不能直接作为筛选依据，最终仍以统计检验（p 值）为准。

## 与业界标准 SOP 的差距分析

| 步骤       | 业界标准                    | v1.14.x 现状               | 差距             |
| -------- | ----------------------- | ------------------------ | -------------- |
| 峰拾取      | PeakPickerHiRes / XCMS  | pyOpenMS PeakPickerHiRes | 无差距            |
| 跨样本峰对齐   | Join Aligner / OBI-Warp | 0.2 Da bin 粗分组           | 中等             |
| 空白峰过滤    | 样本/空白比 < 5:1 剔除         | 无                        | 缺失（需有空白样本）     |
| 缺失值过滤    | 缺失率 > 50% 的峰删除          | 无（全部保留）                  | 较大缺失           |
| QC样本CV过滤 | CV > 20~30% 的峰删除        | 无                        | 缺失（需有QC样本）     |
| 缺失值填补    | half-minimum / KNN      | 填 0                      | **关键缺失**（扭曲分布） |
| 样本归一化    | TIC / PQN / median      | max/median/sum           | 基本达标           |
| 批次校正     | ComBat / QC-LOESS       | 无                        | 较大缺失           |
| **对数变换** | **几乎必做，log₂ 或 ln**      | **无**                    | **关键缺失**       |
| **数据缩放** | **Pareto scaling**      | **无**                    | **较大缺失**       |
| 单变量统计    | Wilcoxon / t 检验 + FDR   | 仅 fold change            | 较大缺失           |
| 特征数量决策   | p 值阈值驱动                 | 硬截断前 50                  | 缺失             |
| 多重检验校正   | BH-FDR                  | 无                        | 缺失             |

## 架构重构决策（2026-04-21 讨论）

### 背景

在讨论 v1.15.0 的具体落地时，发现当前三阶段流程存在根本性的结构问题：**归一化被放在了阶段1（单文件峰拾取阶段），而特征选择在阶段2，两者顺序与标准 SOP 不符，且阶段2同时承担了"对齐"和"特征选择"两件事。**

### 决定：按标准流程重组三阶段

标准流程顺序：

```
raw spectra → peak picking → peak alignment → blank subtraction
  → missing value filtering → normalization → (log + scaling) → 统计检验
```

对应到三阶段的新职责划分：

**阶段1 — 只做峰拾取**

- 保留：`PeakPickerHiRes` 峰拾取逻辑
- 保留：归一化统计量收集（`normalization_stats` 中的 sum/median/max），因为阶段3需要用
- **移除**：归一化的实际应用（删除 `NormalizationManager` 调用块，即 L169-195）

**阶段2 — 对齐 + 质量过滤，产出特征备选池**

- 保留：0.2 Da 粗分组（跨样本峰对齐）
- **新增**：缺失值过滤 —— 统计每个 `mz_group` 在**所有样本**中的出现率，低于 `(1 - MAX_MISSING_RATE)` 的组丢弃
  - 关键：必须用**全样本总出现率**，不能沿用当前的分类别出现率（`_passes_selection_criteria` 中按 class_0/class_1 分别算的逻辑是错的）
- **占位**：空白峰过滤（blank subtraction）—— 需用户提供空白样本，当前 UI 无支持，加注释占位，跳过执行
- **移除**：fold change 筛选、`ml_score` 排序、`head(MAX_FEATURES)` 硬截断（这些属于特征选择，必须在归一化之后做）

**阶段3 — 构建矩阵 + 归一化（+ 暂留 fold change 过滤）**

- 保留：原始强度矩阵构建逻辑
- **新增**：矩阵构建完成后，用阶段1缓存的 `normalization_stats` 对每列（每个样本）做归一化
- **暂留**：fold change 过滤作为阶段3末尾的临时步骤，待 v1.15.1 替换为 Wilcoxon 检验后删除

### 为什么归一化要在阶段3而不是阶段1

- TIC/median/max 归一化因子应基于"真实信号"计算，理论上应在质量过滤后再算
- 但更重要的原因：**特征选择（fold change / 统计检验）必须建立在归一化数据上**，否则检测到的差异可能是样本上样量差异而非生物学差异
- 当前在阶段1归一化、阶段2用归一化后的数据算 fold change，虽然结果可接受，但流程语义混乱，归一化因子来自单样本内所有峰（包括噪声），且缺失值（填0）污染了后续所有统计

### 改后的三阶段流程

```
阶段1：峰拾取（保存 normalization_stats，不归一化）
  ↓
阶段2：0.2 Da 分组对齐 → 全样本缺失率 > 50% 过滤 → 产出特征备选池
  ↓
阶段3：构建原始强度矩阵 → 样本内归一化 → fold change 过滤（暂留，待 v1.15.1 替换）
```

原计划表中"在阶段1归一化之后加 log 变换"需要调整：log 变换应在阶段3归一化之后加，不是阶段1。

## 潜在风险

- **无空白样本 / 无QC样本**：空白峰过滤和 QC CV 过滤无法执行，需在方法部分说明并用缺失值过滤替代
- **样本量小（每类 < 5）**：Wilcoxon 检验功效不足，p 值分布需人工核查
- **实验设计完全混淆**：批次与类别标签完全共线时，任何批次校正均无法区分生物学差异和批次差异，是实验设计问题，无法通过代码解决
- **精确对齐容差**：0.01 Da 适用于高分辨率质谱，需根据仪器精度调整
