# v1.15.x 更新日志

## 背景

v1.14.x 预处理流程与业界代谢组学 SOP 存在三类差距：

1. **流程顺序错误**：归一化在阶段1（单文件级别），特征选择在阶段2，顺序与标准 SOP 相反，导致特征选择建立在未归一化的数据上
2. **特征筛选缺乏规范**：`ml_score = fold_change × coverage` 排序后硬截前50，无统计检验支撑
3. **缺失关键处理步骤**：缺失值直接填0、无 log 变换、无 Pareto scaling，数据分布假设错误

v1.15.x 目标：按标准 SOP 重组三阶段流程，补齐缺失步骤。

---

## 三阶段新职责划分

```
阶段1：峰拾取 + 收集归一化统计量（不应用归一化）
  ↓
阶段2：0.2 Da 分组对齐 → 全样本缺失率 > 50% 过滤 → 产出特征备选池
  ↓
阶段3：构建原始强度矩阵 → 样本内归一化 → [后续步骤见下方计划]
```

---

## 已完成

### v1.15.1 — 归一化位置调整（2026-04-24）

**改动**：将归一化从阶段1移至阶段3矩阵构建后。

| 文件 | 位置 | 改动 |
|---|---|---|
| `data_preprocessor.py` | `_phase1_discover_peaks` | 删除归一化应用块，只保留 `normalization_stats` 统计量收集 |
| `data_preprocessor.py` | `_build_unified_matrix` | 提取原始强度后，按 `normalization_stats[file_id][method]` 对每个样本做除法归一化 |
| `data_preprocessor.py` | `_extract_intensity` | 注释更新，明确返回原始强度值 |

**原因**：特征选择（fold change / 统计检验）必须在归一化数据上进行，否则检测到的差异可能是样本上样量差异而非生物学差异。

---

### v1.15.2 — 阶段2全样本缺失率过滤（2026-04-24）

**改动**：用全样本缺失率过滤替换原有的分类出现率 + ml_score + 硬截断逻辑。

| 文件 | 位置 | 改动 |
|---|---|---|
| `config.py` | 参数区 | 新增 `MAX_MISSING_RATE = 0.5` |
| `data_preprocessor.py` | `_passes_selection_criteria` | 完全重写：峰群在 > 50% 全样本中缺失则丢弃，不再按分类别算出现率 |
| `data_preprocessor.py` | `_phase2_consensus_peaks` | 新增 `total_files`；删除 `ml_score` 排序和 `head(MAX_FEATURES)` 截断；改为按 `consensus_mz` 升序排列 |

**原因**：原逻辑按类别分别算出现率（OR 逻辑），若批次效应与类别共线会保留批次标记物；全样本出现率直接反映峰的检测一致性，是 SOP 标准做法。

## 待完成

### v1.15.3 — 阶段3后处理链补齐

在 `_build_unified_matrix` 归一化之后，依次串联：

```
归一化（已完成）→ half-minimum 填补 → log₂(x+1) → fold change 暂留筛选 → Pareto scaling
```

**注意**：
- half-minimum 是矩阵级操作（同一特征在所有样本的非零最小值的一半），不能在 `_extract_intensity` 中做，需在整张矩阵构建后按行计算
- fold change 暂留筛选放在 Pareto scaling 之前（Pareto 后数值无量纲，fold change 失去生物学意义）
- `config.py` 补充 `LOG_TRANSFORM = True`、`SCALING_METHOD = 'pareto'`

**论文表述**：*"剔除在 50% 以上样本中缺失的特征，剩余缺失值采用 half-minimum 填补；强度数据经 log₂(x+1) 变换后进行 Pareto scaling。"*

### v1.15.4 — 统计检验替换 fold change

依赖 v1.15.3 完成后实施。用 Mann-Whitney U + BH-FDR 替换阶段3末尾的 fold change 暂留筛选。

`config.py` 新增 `P_VALUE_THRESHOLD = 0.05`、`FDR_CORRECTION = True`；`MAX_FEATURES` 改为 `None`（由 p 值阈值驱动）。

**论文表述**：*"采用 Mann-Whitney U 检验进行组间差异特征筛选（p < 0.05，Benjamini-Hochberg FDR 校正）。"*

---

### v1.15.5 — 批次效应处理

根据数据条件选路线（需在实验设计未完全混淆的前提下）：

- **路线 A（有 pooled QC）**：QC 样本均值比例校正，无需额外依赖

## 潜在风险

- **无空白样本 / 无 QC 样本**：对应过滤步骤跳过执行，在论文方法部分说明
- **样本量小（每类 < 5）**：Wilcoxon 检验功效不足，p 值分布需人工核查
- **实验设计完全混淆**：批次与类别标签完全共线时，批次校正无效，属于实验设计问题
