# v1.15.x 更新日志

## 背景与动机

通过与业界标准代谢组学 SOP 的系统对比，发现 v1.14.x 的预处理流程存在两类问题：

**问题一：特征选取缺乏学术规范**
阶段2通过自制的 `ml_score = fold_change × coverage` 排序并硬性截取前50个特征。该做法缺乏统计检验支撑，且两个问题不独立——若批次效应与类别标签共线，fold change 筛出的"特征"实为批次标记物，而非生物学差异。

**问题二：批次间差异导致混合批次后预测性能大幅下降**
当前归一化仅做样本内强度缩放（max/median/sum），对样本间系统性偏移无效。混合批次后性能下降，根本原因是模型学到了批次差异而非生物学差异。

**更深层的根因：缺失了业界默认的数据处理步骤**
从"峰拾取结果"到"可用于建模的特征矩阵"，整个中间过程缺失了质量过滤层、log 变换、Pareto 缩放、正确的缺失值填补等业界默认步骤，导致后续所有统计分析均建立在错误假设上。

v1.15.x 目标：系统性补齐与业界 SOP 的差距，使预处理流程达到可在论文中完整描述的学术规范。

---

## 完整的标准预处理流程（目标架构）

```
峰拾取（pyOpenMS PeakPickerHiRes）
  ↓
跨样本峰对齐
  ↓
质量过滤层 ──────────────────────────────────────────────
  ├─ 空白峰过滤     → 样本/空白强度比 < 5:1 的峰剔除
  ├─ 缺失值过滤     → 在 > 50% 样本中缺失的峰剔除
  └─ QC样本CV过滤  → QC样本中 CV > 20~30% 的峰剔除（分析重现性差）
  ↓
缺失值填补（half-minimum，对过滤后剩余峰）
  ↓
样本内归一化（TIC / median）
  ↓
批次校正（ComBat / QC比例校正）
  ↓
log₂(x+1) 变换
  ↓
Pareto scaling
  ↓ ─── 以上步骤产出"特征备选池" ───
统计检验（Wilcoxon + BH-FDR）+ Fold Change 过滤
  ↓
最终特征矩阵（用于建模）
```

## 关于变异系数（CV）的两种用法

CV 在流程中出现两次，**含义和操作方向相反**，需严格区分：

| 位置 | 计算对象 | CV 含义 | 操作 |
|------|----------|---------|------|
| 质量过滤层（QC样本） | 同一峰在多个 QC 重复样本间的波动 | 分析仪器重现性 | CV **高** → **剔除**（这个峰测不准，是噪声） |
| 特征选择层（生物样本） | 同一峰在所有生物样本间的波动 | 生物学变异程度 | CV **高** → 可能有区分度，但仍需统计检验确认 |

**注意**：生物样本中 CV 高不等于特征有效——高 CV 可能是真实生物学差异，也可能是样本质量不均或批次噪声。因此生物样本的 CV 只能辅助参考，不能直接作为筛选依据，最终仍以统计检验（p 值）为准。

## 与业界标准 SOP 的差距分析

| 步骤 | 业界标准 | v1.14.x 现状 | 差距 |
|------|----------|-------------|------|
| 峰拾取 | PeakPickerHiRes / XCMS | pyOpenMS PeakPickerHiRes | 无差距 |
| 跨样本峰对齐 | Join Aligner / OBI-Warp | 0.2 Da bin 粗分组 | 中等 |
| 空白峰过滤 | 样本/空白比 < 5:1 剔除 | 无 | 缺失（需有空白样本） |
| 缺失值过滤 | 缺失率 > 50% 的峰删除 | 无（全部保留） | 较大缺失 |
| QC样本CV过滤 | CV > 20~30% 的峰删除 | 无 | 缺失（需有QC样本） |
| 缺失值填补 | half-minimum / KNN | 填 0 | **关键缺失**（扭曲分布） |
| 样本归一化 | TIC / PQN / median | max/median/sum | 基本达标 |
| 批次校正 | ComBat / QC-LOESS | 无 | 较大缺失 |
| **对数变换** | **几乎必做，log₂ 或 ln** | **无** | **关键缺失** |
| **数据缩放** | **Pareto scaling** | **无** | **较大缺失** |
| 单变量统计 | Wilcoxon / t 检验 + FDR | 仅 fold change | 较大缺失 |
| 特征数量决策 | p 值阈值驱动 | 硬截断前 50 | 缺失 |
| 多重检验校正 | BH-FDR | 无 | 缺失 |

## 计划改动

> **关键前提**：质量过滤、log 变换和缺失值填补是"地基"，必须先于统计检验实施。
> 在错误的数据分布上跑统计检验，p 值本身不可信。

---

### v1.15.0 — 地基补齐（质量过滤 + log 变换 + 缺失值填补 + Pareto 缩放）

**优先级最高，应最先实施。**

| 文件 | 改动位置 | 改动内容 |
|------|----------|----------|
| `data_preprocessor.py` | `_phase2_consensus_peaks`（L201）对齐之后、特征选择之前 | 新增质量过滤步骤：缺失率 > 50% 的峰剔除（空白峰过滤和 QC CV 过滤在有对应样本时启用） |
| `data_preprocessor.py` | `_extract_intensity`（L413） | 缺失值从填 0 改为 half-minimum（同特征所有非零值的一半） |
| `data_preprocessor.py` | `_phase1_discover_peaks`（L126）归一化之后 | 新增 `log2(intensity + 1)` 变换步骤 |
| `data_preprocessor.py` | `_build_unified_matrix`（L378） | 矩阵构建完成后增加 Pareto scaling（每列减均值，除以标准差的平方根） |
| `config.py` | 参数区 | 新增 `LOG_TRANSFORM = True`、`SCALING_METHOD = 'pareto'`、`MAX_MISSING_RATE = 0.5` |

**论文中可表述为：**
*"剔除在 50% 以上样本中缺失的特征，剩余缺失值采用 half-minimum 填补；强度数据经 log₂(x+1) 变换后进行 Pareto scaling。"*

**预计工作量：1.5 小时**

| 文件 | 改动位置 | 改动内容 |

**论文中可表述为：**
*"采用 Mann-Whitney U 检验进行组间差异特征筛选（p < 0.05，Benjamini-Hochberg FDR 校正）。"*

**预计工作量：1.5 ~ 2 小时**

### v1.15.2 — 批次效应处理

**前提：确认实验设计未完全混淆（两类样本不完全按批次分离），否则任何校正方法均无效。**

根据是否有 QC 样本，选择其中一条路线：

**路线 A：有 pooled QC 样本**
每个批次中用 QC 样本均值做比例校正，不需要额外依赖。工作量小。

**路线 B：无 QC 样本，有 batch 标签**
在 UI 分类对话框新增 batch 标签输入，使用 `pyComBat`（`pip install combat`）做跨批次校正。工作量中等，主要在 UI 层。

**路线 C：最小侵入（无 QC、无 batch 标签）**
在特征筛选时额外计算批次方差占比（η²），若批次能解释该特征方差 > 30% 则丢弃。治标不治本，但无需修改 UI。

**预计工作量：路线A 1小时 / 路线B 3~4小时 / 路线C 1.5小时**

### v1.15.3 — 精确峰对齐（可选）

将 0.2 Da 粗 bin 替换为基于质心的贪心聚类对齐，容差由 `ALIGNMENT_TOLERANCE`（默认 0.01 Da）控制，同一簇内取强度加权质心作为共识 m/z。


## 潜在风险

- **无空白样本 / 无QC样本**：空白峰过滤和 QC CV 过滤无法执行，需在方法部分说明并用缺失值过滤替代
- **样本量小（每类 < 5）**：Wilcoxon 检验功效不足，p 值分布需人工核查
- **实验设计完全混淆**：批次与类别标签完全共线时，任何批次校正均无法区分生物学差异和批次差异，是实验设计问题，无法通过代码解决
- **精确对齐容差**：0.01 Da 适用于高分辨率质谱，需根据仪器精度调整
