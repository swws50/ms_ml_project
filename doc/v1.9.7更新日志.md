## 🎯 核心变更概述

本次更新将训练验证方法从"500次蒙特卡洛重采样"升级为"标准的重复分层K折交叉验证"，显著提升了模型评估的科学性和可信度，使验证方法符合医疗AI国际标准。

## ✨ 新增功能

### 1. 重复分层K折交叉验证 (Repeated Stratified K-Fold CV)

**更新内容**:

- 实现了 `RepeatedStratifiedKFold` 交叉验证策略
- 配置为 5折交叉验证 × 20次重复 = 100次训练
- 确保每个样本在整个验证过程中被测试恰好20次

**技术细节**:

```python
# config.py
CV_SPLITS = 5           # 5折交叉验证
CV_REPEATS = 20         # 重复20次
CV_RANDOM_STATE = 42    # 固定随机种子确保可复现性

CROSS_VALIDATOR = RepeatedStratifiedKFold(
    n_splits=CV_SPLITS,
    n_repeats=CV_REPEATS,
    random_state=CV_RANDOM_STATE
)
```

**优势**:

- ✅ 每个样本测试次数完全均等（无偏估计）
- ✅ 消除了样本重复测试导致的虚假低方差
- ✅ 提供更真实的泛化能力评估
- ✅ 符合FDA/NMPA医疗器械验证要求
- ✅ 符合Nature/Lancet等顶级期刊标准

### 统计可靠性提升

**交叉验证的优势**:

1. **无偏估计**: 每个样本被测试次数完全相同
2. **真实方差**: 无样本重复导致的方差低估

- 某些样本可能被测试70次，某些130次
- 测试集重复导致虚假的低方差
- 对小数据集尤其不可靠

## 🔬 验证方法学说明

### 交叉验证原理

**5折交叉验证 (单次)**:

```
数据集分为5等份，每份轮流作为测试集：

折1: [测试集1] [训练集2-5]
折2: [训练集1] [测试集2] [训练集3-5]
折3: [训练集1-2] [测试集3] [训练集4-5]
折4: [训练集1-3] [测试集4] [训练集5]
折5: [训练集1-4] [测试集5]

结果：每个样本被测试恰好1次
```

**重复20次**:

- 每次重复时重新随机打乱数据
- 每个样本总共被测试20次
- 20次的结果用于计算置信区间

**分层策略**:

- 确保每折中类别比例与整体数据一致
- 对于不平衡数据尤其重要
