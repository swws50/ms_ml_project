# 质谱数据归一化工作日志

## 核心概念理解

### 1. 全局归一化 vs 局部归一化

- [ ] **全局归一化**：对整批样本统一处理（训练集所有样本一起计算参数）
- [ ] **局部归一化**：每个文件单独处理（会破坏样本间可比性）
- [ ] **结论**：疾病诊断必须用全局归一化

### 2. 外部验证的归一化策略

- [ ] **核心原则**：外部验证必须使用训练集的归一化参数
- [ ] **原因**：保证同一把"尺子"，否则无法比较
- [ ] **操作**：
  - 训练时计算并保存归一化参数（如参考谱、中位数）
  - 验证时加载训练参数，不重新计算

### 3. 批次效应的解决方案

- [ ] **实验层面**（最重要）：
  
  - 标准化操作流程（SOP）
  - 样本随机化顺序
  - 统一仪器和操作员

- [ ] **没有内标时的方案**：
  
  - 准备QC样本（混合所有研究样本）
  - 每10个样本插入1个QC
  - 使用PQN归一化

## QC样本（Quality Control）

### 制备

- [ ] 从所有研究样本中各取等量混合
- [ ] 分装成100-200管小份
- [ ] -80°C保存，整个研究使用同一批

### 作用

- [ ] **监控数据质量**：计算QC的CV（变异系数），要求<30%
- [ ] **发现批次效应**：比较训练期和验证期的QC信号
- [ ] **校正批次差异**：校正因子 = QC_训练 / QC_验证

### 插入策略

- [ ] 每10个样本插入1个QC
- [ ] 每天开始和结束都测QC
- [ ] 样本顺序随机化（病例和对照混合）

## PQN归一化（Probabilistic Quotient Normalization）

### 核心原理

- [ ] **目的**：区分技术误差（稀释）和生物学差异
- [ ] **假设**：大多数代谢物（>50%）不受疾病影响
- [ ] **方法**：用中位数"投票"，让多数派决定归一化因子

### 计算步骤

1. [ ] 计算参考谱（所有样本或QC的中位数谱）
2. [ ] 计算每个样本与参考谱的比值（逐个代谢物）
3. [ ] 取每个样本比值的中位数作为归一化因子
4. [ ] 用该因子归一化整个样本

### 为什么有效

- [ ] **中位数对异常值不敏感**：少数异常代谢物不影响归一化因子
- [ ] **去除稀释效应**：大多数代谢物的共同变化被归一化因子捕获
- [ ] **保留生物学差异**：少数疾病相关代谢物的变化被保留

### 为什么不能单独归一化

- [ ] 没有内标 = 没有固定参照
- [ ] 单独归一化 = 每个样本用不同的"尺子"
- [ ] 必须建立全局参考系（参考谱）才能比较

## 完整工作流程

### 训练阶段

1. [ ] 准备QC样本
2. [ ] 采集数据（每10个样本插入QC）
3. [ ] 计算QC参考谱：`qc_ref = median(train_qc)`
4. [ ] PQN归一化训练数据
5. [ ] **保存参考谱**：`save('qc_reference.npy')`
6. [ ] 训练模型

### 外部验证阶段

1. [ ] 采集外部数据（插入QC，同一批）
2. [ ] 加载训练时的参考谱
3. [ ] 检查QC稳定性：`CV = std(QC_external/QC_train) / mean(...)`
4. [ ] 如果CV>30%，进行QC校正：`data × (QC_train / QC_external)`
5. [ ] 用训练参考谱进行PQN归一化（不重新计算）
6. [ ] 输入模型预测

## 关键注意事项

- [ ] **绝对不能**：外部验证时重新计算归一化参数
- [ ] **必须保存**：训练时的参考谱、归一化参数
- [ ] **QC监控**：CV>30%说明批次效应严重，需要校正
- [ ] **PQN局限**：如果>50%代谢物都变化，PQN会失效

## 方法对比

| 方法     | 优点     | 缺点     | 适用场景     |
| ------ | ------ | ------ | -------- |
| 内标归一化  | 最准确    | 需要添加内标 | 有条件时首选   |
| QC+PQN | 稳健，可监控 | 需要准备QC | 无内标时推荐 ✓ |
| 仅PQN   | 简单     | 无法监控批次 | 批次效应小时   |
| 简单中位数  | 最简单    | 会压缩差异  | 不推荐      |
